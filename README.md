# Fate — فال تاروت و لنورماند

وب‌اپ فال تاروت (۷۸ کارت) و لنورماند (۳۶ کارت) با رندوم واقعی — کوانتومی (ANU)، اتمسفری (random.org) و آفلاین (CSPRNG دستگاه). قابل نصب روی گوشی (PWA) و کاملاً آفلاین پس از اولین بازدید.

## استقرار روی GitHub Pages
1. یک مخزن جدید بساز و همهٔ فایل‌های این پوشه را در ریشهٔ آن آپلود کن.
2. در **Settings → Pages**، بخش *Build and deployment* را روی **Deploy from a branch** و شاخهٔ `main` (پوشهٔ `/root`) بگذار.
3. بعد از یکی دو دقیقه، برنامه روی `https://USERNAME.github.io/REPO/` بالا می‌آید.

## نصب روی گوشی
- **اندروید (کروم):** آدرس را باز کن → منوی ⋮ → **Add to Home screen / نصب برنامه**.
- **آیفون (سافاری):** آدرس را باز کن → دکمهٔ Share → **Add to Home Screen**.

پس از نصب، برنامه مثل اپ مستقل و تمام‌صفحه باز می‌شود و بدون اینترنت هم کار می‌کند (منبع آفلاین).

## کلید شخصی ANU (اختیاری)
برای API کوانتومی جدید می‌توانی از [quantumnumbers.anu.edu.au](https://quantumnumbers.anu.edu.au) کلید رایگان بگیری و در خود برنامه (منبع کوانتومی → تیک «کلید شخصی») ذخیره کنی. کلید فقط در localStorage مرورگر خود کاربر می‌ماند و هرگز در سورس یا مخزن قرار نمی‌گیرد.

## ساختار
```
index.html      برنامهٔ کامل (تک‌فایل، فونت‌ها امبد)
manifest.json   مانیفست PWA
sw.js           سرویس‌ورکر (کش آفلاین)
icons/          آیکون‌های برنامه
```
